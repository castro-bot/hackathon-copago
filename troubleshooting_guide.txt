# Hackathon Copago - Setup & Troubleshooting Findings

This document summarizes the issues encountered and solutions applied while setting up the Next.js + FastAPI monorepo environment inside WSL (Windows Subsystem for Linux).

## 1. WSL and pnpm Version Conflicts
**Issue:** Running `pnpm install` in WSL failed with an `isDriveExFat` error referencing a Windows network path (`\\wsl.localhost\Ubuntu\...`).
**Cause:** The terminal was inadvertently using the Windows host version of `pnpm` (which accesses WSL files via UNC paths that Windows Node.js struggles to validate) rather than the newly installed Linux native version.
**Solution:** Force the terminal to use the Linux version of `pnpm` by either specifying its absolute path (`~/.local/share/pnpm/pnpm`) or completely restarting the WSL terminal session to apply the correct `.bashrc` PATH.

## 2. pnpm Ignored Build Scripts Blocking Server Startup
**Issue:** `pnpm dev` crashed immediately with `[ERR_PNPM_IGNORED_BUILDS]`.
**Cause:** `pnpm` detected unapproved package build scripts (e.g., `msw`, `unrs-resolver`). The `.npmrc` setting `ignore-scripts=true` blocked them during installation, causing strict checks to fail during script execution.
**Solution:** Run `pnpm approve-builds` to explicitly authorize the safe scripts to run, or remove `ignore-scripts=true` from `.npmrc` and reinstall.

## 3. Missing Python Backend Dependency (PyPDF2)
**Issue:** The FastAPI backend crashed on startup with `ModuleNotFoundError: No module named 'PyPDF2'`.
**Cause:** A required package used in `api/pdf_reader.py` was not documented in the project's initial `requirements.txt`.
**Solution:** Manually install the package via `pip install PyPDF2` and append it to `requirements.txt` to ensure reproducible setups.

## 4. Port Confusion (404 Not Found)
**Issue:** Navigating to `http://127.0.0.1:8000` displayed `{"detail": "Not Found"}`.
**Cause:** Port 8000 belongs to the FastAPI backend, which does not serve a root UI endpoint (it only listens on specific paths like `/api/chat`).
**Solution:** The user must access the Next.js frontend UI by navigating to `http://localhost:3000`. The frontend will internally proxy API requests to port 8000.

## 5. Zod Peer Dependency Mismatch (Module not found: Package path ./v4)
**Issue:** The Next.js frontend threw a compilation error: `Module not found: Package path ./v4 is not exported from package .../zod`.
**Cause:** The newer `@ai-sdk/gateway` package requires a version of `zod` that exports `/v4`. Upgrading `zod` to a newer major version (like `4.x`) failed because strict peer dependency rules forced `pnpm` to download a fallback older copy (`3.23.8`) for the SDK, which didn't contain the export.
**Solution:** 
1. Pin `"zod": "3.24.1"` in `package.json`. Version `3.24.1` is the "bridge" version that satisfies `3.x` peer dependencies while providing the new `/v4` export path.
2. Purge cached resolutions by deleting `node_modules`, `pnpm-lock.yaml`, and `.next`.
3. Reinstall using `pnpm install`.
